# KEPCO ES 프로젝트 참고 자료 및 기획 문서 보관함 (`docs/`)

본 디렉토리는 켑코이에스(주) 사업관리시스템(PMS) 및 전자입찰시스템(SRM) 프로토타입 개발을 위한 기획·설계 산출물 및 디자인 참조 리소스를 체계적으로 분류·보관하는 공간입니다.

> 📘 **디자인/UI/UX 가이드라인**:  
> 전체 시스템의 공통 컬러, 타이포그래피, 레이아웃, 컴포넌트 표준은 루트의 [`DESIGN_GUIDE.md`](../DESIGN_GUIDE.md)를 참조하세요.

---

## 폴더 구조 및 세부 설명

### 1. 📁 `specs_pdf/` (기획 및 설계 명세서)
- **`[설계] 로그인 화면.pdf`** : PMS / SRM 통합 로그인 화면 기획 및 UI 와이어프레임
- **`[참고] SRM 상세화면.pdf`** : SRM 입찰공고 현황(상세정보) - 입찰계획 정보 및 '입찰계획으로 되돌리기' 모달 팝업 명세서 (총 4페이지)
- **`[참고]진행상태별 업무 관리.pdf`** : PMS 계약관리 7-Step 입찰계획 현황 (예정가/예비가 산출 프로세스)
- **`[참고]협력업체 신청(팝업).pdf`** : SRM 협력업체 5-Step 등록 신청 위저드 팝업 명세서

### 2. 📁 `design_refs/` (화면 디자인 참고 시안)
화면별 상세 레이아웃, 컬러, 컴포넌트 배치를 정의한 고해상도 디자인 참조 이미지들입니다.
- `[참고]대시보드.jpeg` : PMS 종합 대시보드 화면
- `[참고]왼쪽메뉴.jpeg` : PMS 좌측 GNB 사이드바 메뉴 및 하단 퀵링크
- `[참고]로그인 화면.jpeg` : 포털 로그인 화면 비주얼
- `[참고]신규프로젝트 등록.jpeg` : 계약 형태 선택 모달 화면
- `[참고]검색 및 조회 화면_구성 참고.jpeg` : 프로젝트 현황 검색/조회 레이아웃 구성
- `[참고]검색 및 조회 화면_디자인 참고.jpeg` : 프로젝트 현황 상세 비주얼 디자인
- `[참고]프로젝트 상세.jpeg` : 프로젝트 투자·상환·타임라인 상세 화면
- `[참고]계획대비 실적현황.jpeg` : 자금관리 계획 대비 실적 다차원 집계 화면
- `[참고]사업결산.jpeg` : 사업결산 및 정산 현황 화면
- `[참고]통계.jpeg` : 연도별/사업별 통계 종합 분석 화면
- `[참고]프로젝트 정보 입력(정보입력화면 예시).jpeg` : 프로젝트 추진 단계 정보 입력 화면(`ProjectPromotion.html`)

### 3. 📁 `menu_excel/` (공식 메뉴 구조도)
- **`[참고]메뉴구조도(PMS).xlsx`** : PMS 전체 메뉴 1D ~ 4D 및 기능 명세서
- **`[참고]메뉴구조도(SRM).xlsx`** : SRM 사내담당자(10대 메뉴) 및 협력업체(5대 메뉴) 역할별 메뉴 구조도

### 4. 📁 `planning/` (화면 기획서)
- **`SRM_대시보드_프로토타입_작업계획서.md`** : SRM 권한별 대시보드 4종의 구성·데이터·동작 정의 (DESIGN_GUIDE 6.7이 참조)

### 5. 📁 `extracted_data/` (파싱 및 분석 데이터)
- 메뉴구조도 엑셀에서 추출한 JSON/텍스트 데이터
- PDF 명세서에서 분석 추출한 텍스트 및 페이지별 렌더링 검토 이미지
